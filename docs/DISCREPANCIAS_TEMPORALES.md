# Discrepancias temporales

This document describes the review workflow for date inconsistencies found in procurement records. It contains no instance-specific contract examples.

## Review steps

1. Compare publication, submission-deadline, award, formalization, and modification dates.
2. Open the original PLACSP notice and supporting documents.
3. Distinguish source-data errors from timezone, amendment, cancellation, or later-publication effects.
4. Record a correction only when an authoritative document supports it; preserve the source value and correction provenance.
5. Treat automated alerts as review prompts, not legal findings.
